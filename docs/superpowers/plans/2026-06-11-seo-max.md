# SEO-Max: win-everything pass (2026-06-11)

Goal: maximal indexation + SEO competitiveness + caching everywhere it pays.

## 1. Canonical URL normalization (proxy, hot path)
Mixed case / trailing slash → 301 to canonical form (`/EN/About/` → `/en/about`).
Today: 404. Duplicate-URL signals eliminated at the edge.

## 2. Posts model (the big SEO lever)
- `pages.kind` ('page'|'post') + `pages.author`
- post publishes → `Article` JSON-LD (headline, author, datePublished from first
  publish — new `pages.first_published_at`, dateModified, image = og)
- `PostList` puck component: latest N posts of site+locale (server-cached,
  tag `posts:{siteId}:{locale}`, invalidated on post publish)
- RSS: `/feed.xml` per host+locale (posts, full meta), `<link rel=alternate>`
  in public layout, Last-Modified/304 support
- admin: kind selector + author on create/edit

## 3. OG image picker + Organization
- root puck field `ogImage` (media picker) → og:image/twitter:image use it,
  generated card stays as fallback
- site.settings.org {name, logoMediaKey?, sameAs[]} → Organization JSON-LD on
  every page; settings UI fields
- site.settings.seo.googleVerification / bingVerification → metadata
  verification per site (Search Console/Webmaster proof)

## 4. Crawl-budget caching
- sitemap: shard via sitemap index when >45k URLs (`/sitemaps/{n}.xml`)
- sitemap + RSS + robots: `Last-Modified` + `If-Modified-Since` → 304
  (crawlers re-poll constantly; 304 = near-zero cost)

## 5. CDN purge implementations
`RevalidateClient` chain gains real providers (env-selected):
- Cloudflare: purge by URL (zone + token)
- CloudFront: CreateInvalidation (distribution id)
Tags carry paths → exact URL purge on publish. Unit-tested request shaping.

## 6. Custom 404 per site
Branded not-found in the public segment with SearchBox — keeps lost visitors
(and crawlers see consistent 404 with site chrome).

## 7. Verify
Build, integration tests (posts/RSS/canonical), e2e, LHCI budgets hold, docs.
