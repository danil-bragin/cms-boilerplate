# Admin UX overhaul — kill raw JSON, build real editors (2026-06-11)

Goal: no admin surface forces raw JSON / comma-strings / window.prompt. Every
field uses a proper component. Build small reusable primitives, apply across
surfaces.

## Wave 1 — reusable input primitives
New `apps/web/src/components/admin/inputs.tsx`:
- `TagInput({ value, onChange, placeholder, validate? })` — chip editor for
  string[] (Enter/comma adds, ✕ removes, per-item validate → red chip)
- `UrlListInput` — TagInput preset validating `new URL()` (sameAs)
- `LocaleSelect({ locales, value, onChange })` — dropdown
- `CheckboxGroup({ options, value, onChange })` — multi-select for enums
- `Field({ label, hint, error, children })` — consistent labeled wrapper
Unit-test TagInput add/remove/validate.

## Wave 2 — Sites (site-forms.tsx)
- domains/locales → `TagInput` (hostname / locale-code validate)
- defaultLocale → `LocaleSelect` from entered locales
- org.sameAs → `UrlListInput`; org.logoUrl → MediaField picker
- verify settings hydration (siteDto lacks settings type — add optional
  `settings` to the page's prop type so SEO/org load)

## Wave 3 — Menus (new MenuTreeEditor, replaces JSON textarea)
- rows: each item = { href (text or page picker), per-locale label inputs,
  children[] }; add/remove/reorder item + child; one nesting level (contract cap)
- builds the `items` array; no JSON ever shown
- href: free text now, page-picker later (keep simple: datalist of published paths)

## Wave 4 — GSC + Authors + Webhooks
- GSC: drop JSON textarea → file input (read .json) OR client_email + private_key
  textarea fields; parse client-side, show client_email back; add propertyUrl field
- Authors: sameAs → UrlListInput; avatarKey → MediaField picker
- Webhooks: events → CheckboxGroup(WEBHOOK_EVENTS); active toggle

## Wave 5 — Pages duplicate + polish
- duplicate: replace window.prompt with inline path field
- empty states for sites/pages/redirects lists

## Verify each wave: tsc, build, manual smoke via curl/admin. Final: e2e + lint + commit.
