# SEO + Speed Optimization Plan (2026-06-11)

Market research (June 2026) digested; fabricated claims rejected (no new CWV
metrics, no "LCP 2.0s update"; thresholds remain LCP≤2.5s / INP≤200ms / CLS≤0.1).

## Audit of current state → gaps

| Area | Now | Gap |
|---|---|---|
| Meta | title/description/canonical/hreflang | no OG/Twitter, no robots directives, no per-site metadataBase, no x-default |
| `<html lang>` | hardcoded `en` | must follow locale |
| Sitemap/robots | none (404) | host-aware routes, real lastmod (Google uses it only if accurate) |
| Structured data | none | WebSite + WebPage + BreadcrumbList JSON-LD (SearchAction dead 2024, skip) |
| OG image | none | 1200×630 dynamic via ImageResponse, public route, versioned URL |
| IndexNow | none | Bing/Yandex/Naver + feeds ChatGPT search; key per site, ping on publish (Google: no support — sitemaps remain) |
| Speculation Rules | none | biggest "instant" lever (Chrome p75 LCP 320ms vs 1800ms); document rules, moderate eagerness |
| LCP image | always lazy | `priority` toggle in editor → eager + fetchpriority=high |
| Image formats | original only | imgproxy AUTO_AVIF/AUTO_WEBP (+ CDN Vary: Accept) |
| preconnect | none | imgproxy origin |
| bfcache | OK (static) | add `Permissions-Policy: unload=()` insurance |
| View transitions | none | cross-doc CSS `@view-transition` (Chrome+Safari 18.2, progressive) |
| Compression | next gzip only | nginx reference config: brotli_static + zstd/brotli dynamic |
| llms.txt | — | skip: dead standard (~0.1% bot fetch rate, Google dismisses) |

## Tasks

1. Layout restructure: public root layout at `s/[siteId]/[locale]/layout.tsx`
   (`<html lang>`, speculation rules, preconnect, view-transition CSS);
   admin/preview get own root layouts; delete top `app/layout.tsx`.
2. Full metadata: per-site metadataBase (primary domain), title template,
   robots (`max-snippet:-1, max-image-preview:large, max-video-preview:-1`),
   OG (website type, siteName, locale + alternates, 1200×630 image), Twitter
   `summary_large_image`, hreflang + x-default (link-tag channel only — no
   sitemap duplication, contradiction risk).
3. JSON-LD in page: WebSite, WebPage (datePublished/dateModified), BreadcrumbList.
4. `/og/{pageId}` ImageResponse route (public, versioned `?v=publishedAt`,
   immutable cache), excluded from proxy rewrite.
5. Host-aware `/sitemap.xml` + `/robots.txt` route handlers; lastmod =
   `published_at`; robots: allow all, optional AI-training-bot block via
   `site.settings.seo.blockAiTraining`, Sitemap line.
6. IndexNow: per-site key (seed-generated, `settings.indexNowKey`),
   `/indexnow.txt` key route, BullMQ `seo-ping` queue, worker POSTs
   `api.indexnow.org` on publish/unpublish.
7. Editor: Image `priority` field; render eager + fetchpriority when set.
8. imgproxy AUTO_AVIF/AUTO_WEBP in compose + k8s; docs: CDN `Vary: Accept`.
9. Headers: `Permissions-Policy: unload=()` for public pages.
10. `infra/nginx/` reference config (brotli_static, zstd, gzip fallback, 103 note).
11. Verify: build, prod smoke (head tags, sitemap, robots, og image, indexnow key),
    e2e, commit.

Deferred (documented, not done): cacheComponents/PPR migration (route already
fully static — near-zero gain, real risk), React Compiler (no client-heavy JS),
Early Hints (marginal for cached ISR; nginx ≥1.29 note in config).
